Week of September 21, 2026

Last week at Veza

Veza Web rebuilt the Day Map for speed and added an availability filter, an equipment filter, time off bars and one-click availability shortcuts, and the mobile app added the Route to the unit sign-in and sign-out form. Here is what your team will notice.
 

Veza Web

A faster Day Map

The Day Map is the single-day timeline in Dispatch: one row per driver or unit, with that day's runs laid out across the hours. It was rebuilt so it loads and redraws faster across a full day of runs. Run cards now update in batches instead of one at a time, and the board refreshes on its own when the underlying schedule changes.

How to find it

Dispatch → Day Map

Availability filter on the Day Map

The Availability filter keeps only the drivers or units that are free for a time window you set. You can add more than one window, and each one appears as a pill you can edit or clear.

How to find it

Dispatch → Day Map → filter icon → Availability

One-click ways to find an available driver or unit

The Day Map can now find availability for you, without typing a time. Drag across the timeline, then right-click and choose Find available drivers or Find available units for that span. Right-click a run and use Run Actions → Show compatible Drivers or Show compatible Units for that run's own time, or right-click a driver or unit row and use Row Actions → Find cover options for everything that row is scheduled for that day.

How to find it

Dispatch → Day Map → right-click a timeline selection, a run or a row

Equipment filter on the Day Map

The Equipment filter narrows the Day Map to units that carry every piece of equipment you select, such as a wheelchair lift or a booster seat. It works together with the availability filter and with search.

How to find it

Dispatch → Day Map → filter icon → Equipment

Approved time off shows on the Day Map

Driver rows now show a bar over the hours the driver is away, labelled with the type of leave, for example Unavailable — Vacation. Only approved requests for the selected date appear, and those drivers count as unavailable in the availability filter.

How to find it

Dispatch → Day Map → Driver view
 

Veza Mobile

Unit sign-in and sign-out records the Route

The unit sign-in/out form now includes a Route field, so each submission says which Route the unit was signed in or out for. The Route appears with the driver, unit, date and time on the submission in Veza Web.

How to find it

In Veza Web: Fleet → Sign-In/Out → open a submission → Details
