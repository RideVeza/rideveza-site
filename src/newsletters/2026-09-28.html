Week of September 28, 2026

Last week at Veza

Veza Web adds route import from Excel, unnamed rider counts on stops, stop nicknames, and seat counts on the Day Map. Here is what your team will notice.
 

Veza Web

Import routes from Excel

You can now import routes and riders from an Excel workbook (.xlsx). Choose the operational period and the route start and end dates, then upload the file. Before anything is saved, Veza checks the workbook, shows how many routes and riders are new, modified or unchanged, and lists any issues by sheet and cell.

How to find it

Routes → Add Route → Import from Excel. Use Download template in that window to get the workbook layout.

Unnamed rider counts on stops

A stop can now hold a count of unnamed riders. These are riders you count but do not list by name. Route stops and run stops show this count, and it carries over when runs are generated or split. Run cards in Dispatch show the count and let you mark these riders, and filters include them.

How to find it

Routes → open a route's details → find the stop in the route's steps

Stop nicknames

You can now give a stop a nickname. Use this when the stop is at a recognizable location or place, for example Public Library or Town Hall. Route stops and run stops can each have a nickname, and it shows with the stop in Routes and on runs in Dispatch.

How to find it

Routes → open a route's details → find the stop in the route's steps

Seat counts on the Day Map

Each unit on the Day Map now shows its seat count.

How to find it

Dispatch → Day Map
