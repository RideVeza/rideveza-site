Week of July 20, 2026

Last week at Veza

This week brings run tags and a new staff map in Veza Web, pay summaries in the mobile app, and new control over what parents can track in Veza Guardian. Here is what your team will notice.
 

Veza Web

Tag runs and filter by tag

You can now add tags to a run, from a set list that includes things like Weather, Traffic, Mechanical, Bus Swap and Road Work. The run list can then be filtered to show only the runs with the tag you pick, so you can pull up every run from a bad weather day or a bus swap later on.

How to find it

Dispatch → open a run's details → Run Tags. To filter, use Filter → Run Tags above the run list.

Write notes on riders that bus staff can read

Each rider now has two note boxes. Office Notes stay inside the office. Bus Staff Notes are read by the driver and the attendant in the mobile app, and they also print on the route and run PDFs, so the bus team has them before the run starts.

How to find it

Riders → open a rider's details → Notes tab.

See which buses have arrived at school

A new filter shows only the runs where the bus has arrived at school, or only the runs where it has not. The school name on a run also changes colour once the driver marks the bus as arrived, so you can follow the morning without opening each run.

How to find it

Dispatch → Filter → Bus arrived at school → Yes or No.

See where your staff live on a map

The Staff page now has a map view, with a pin on the home address of every staff member, so you can see who lives near a school or a route.

How to find it

Staff → switch from List to Map at the top of the page.

Riders who must be met at the bus are marked

An asterisk now appears beside the name of any rider who has a Meet at bus note. It shows on every page where riders are listed, so you can spot them without opening the rider's details.
 

Veza Mobile

Bus staff can see their recent pay in the app

Bus staff can now open a summary of their pay for each two week pay period in the mobile app. This includes run pay, expenses and holiday pay.

How to find it

In the mobile app: Resources → Pay Tracker.

School calendars and contacts updated

The school calendars and the contact details shown in the mobile app have been updated.
 

Veza Guardian

Turn off bus tracking for one run

You can now turn tracking off for a single run. Parents stop seeing the live bus and the live ETAs for that run. They still see the run details, the scheduled times, and whether each child was picked up or dropped off. Turn it back on the same way.

How to find it

In Veza Web: Dispatch → open a run's details → click the 3-dot menu → Turn guardian tracking off.

Turn off bus tracking for a whole district

Each district now has its own switch for Guardian app tracking. Turn it off and no run in that district is tracked in the parent app.

How to find it

In Veza Web: Schools & Districts → Districts → open a district's details → Guardian app tracking.
