Week of July 27, 2026

Last week at Veza

Work for the new school year has started, the mobile app has a new hazard assessment form, and Veza Web picked up clearer labels on runs, staff and vehicles. Here is what your team will notice.
 

Veza Web

Routes for the new school year are being loaded

Routes for the coming school year are being added to Veza now. They appear on the Routes page as each one is loaded, and you can switch between school years from the dropdown at the top of the page.

How to find it

Routes → pick the school year from the dropdown at the top of the page.

Run notes now add a tag to the run card

When you write notes on a run, a Notes tag appears on the run card. Clear the notes and the tag goes away. The run list can be filtered by the Notes tag, so you can pull up every run that has notes on it.

How to find it

Dispatch → open a run's details → Run Notes. To filter, use Filter → Run Tags → Notes above the run list.

Staff labels on the Routes table are colour coded

Staff labels on the Routes table now use the same colours as the route details panel. Green means the person was requested for that role. Yellow means a temporary assignment.

How to find it

Routes → the staff columns on the table.

See when staff last used the mobile app

The Staff table has a new Last Mobile App Login column. It shows when each staff member last signed in to the mobile app, and it can be filtered by date.

How to find it

Staff → Last Mobile App Login column.

See which schools each staff member serves

The Staff table has a new Linked Schools column. It lists the schools on the routes each staff member is assigned to.

How to find it

Staff → Linked Schools column.

More seating and equipment detail on the Units table

The Units table has new columns for student capacity, wheelchair spaces, anchors, integrated car seats, benches, lap and shoulder seatbelts, cameras, make and model.

Preferred name and contact email for riders

A rider's details now include a Preferred name field. The Riders table also has a Primary Email column, showing the email address of the rider's primary contact.
 

Veza Mobile

New hazard assessment form for dry runs and new routes

Bus staff can now fill out a Dry Run / Site-Specific Hazard Assessment in the mobile app, listing each hazard by category with the action taken. Completed forms go to the Forms page in Veza Web for the office to review.

How to find it

Forms → Dry Run / Site-Specific Hazard Assessment.
In Veza Web: Forms → Dry Run/Site-Specific Hazard Assessments.

Resources are being updated for the new school year

The documents in the Resources section of the mobile app are being replaced with the versions for the coming school year.

How to find it

Resources → School Calendars, or your organization's own resources list.
