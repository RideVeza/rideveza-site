Week of August 24, 2026

Last week at Veza

The run list can now be sorted and has three new filters, the Route Assessment form was rebuilt with a new printed layout, and the mobile app starts faster. Here is what your team will notice.
 

Veza Web

Sort the run list

The run list can now be sorted by run name or by how late a run is running. Click the sort tag to switch between ascending and descending, so you can bring the runs you care about to the top.

How to find it

Dispatch → the sort button above the run list → Run name or Lateness.

Three new filters on Dispatch

Pre-trip status shows runs by whether the pre-trip inspection is complete or incomplete. Covered roles shows runs where a role is being covered, and you can choose the role type. All riders absent shows only the runs where every rider due to be picked up is marked absent. The options in each filter list are now in alphabetical order.

How to find it

Dispatch → the filter button above the run list.

Hazard ID on hazard forms

Every hazard form now carries a short Hazard ID. It is shown on the form itself and as a column on the list, and the column can be searched and filtered, so a single form can be found and referred to without opening each one.

How to find it

Forms → Hazard Forms.

Assigned route on time off requests

The time off requests table has a new Assigned Route column, showing the routes the person asking for the time off is assigned to, so you can see what needs covering without leaving the page.

How to find it

Staff → Time off requests.
 

Veza Mobile

Route Assessment form rebuilt

The Route Assessment form has a new set of questions, grouped into sections: visibility, highway stops, loading and unloading space, turnarounds, crossings, roads, weather and non-weather risks, weather policy, and other safety concerns. Each question is answered yes or no, notes are optional on every section, and the form records a Pass or Fail result. The PDF now follows the Alberta checklist layout. Assessments submitted before this change still open and print in their original form.

How to find it

Forms → Route Assessment.
In Veza Web: Forms → Route Assessments.

The app starts faster

Map data is no longer loaded every time the app is opened. It now loads only when a map is needed, so the app is ready to use sooner after start-up.
