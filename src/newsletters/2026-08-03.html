Week of August 3, 2026

Last week at Veza

Route change requests are launched, from the mobile app through to review in Veza Web. Dispatch can record why a run was late, Routes has a new assignment status, and the mobile app picked up two changes of its own. Here is what your team will notice.
 

Veza Web

Record why a run was late

A run can now carry one or more late reasons and a note. The list covers traffic, weather, mechanical issues, staffing, medical, student management and more. As soon as you add a reason or a note, Veza puts a Late Details tag on the run, so the run list can be filtered by it.

How to find it

Dispatch → run details → Late details.

New "Potential" assignment status

Role assignments on a route can now be set to Potential, alongside Requested, Permanent and Temporary. It shows in blue on the route card, and it carries through to the route PDF.

How to find it

Routes → open a route's details → set the status on a role assignment.

CT Stops land on the station

When a route comes in from BusPlanner with a CT Stop, Veza now matches it to the transit station at that location instead of relying on the BusPlanner position. The station address is what shows on the route, on the run, and on the PDFs.

More equipment for riders

Mats, sleeves and caps were added to the equipment list, so a rider's care record can record the equipment they travel with.

How to find it

Riders → open a rider's details → Care tab → Add Care Record → Equipment.
 

Veza Mobile

Route change requests

Bus staff can now send a route change request from the app. Each request records the route, the reason, and a note. The office reviews it in Veza Web: approve or decline the request, edit the note, and tick off that the staff member has been contacted and that the route assignment has been updated.

How to find it

Forms → Route Change. In Veza Web: Forms → Route Change Requests → open a request to review it.

Report a hazard that is not tied to a run

The Hazard Form and the Psychological Hazard Form now have a No run option on the Select Run step. Staff can report a hazard that did not happen on a run without picking one from the list.

The run picks up the unit that was inspected

If a driver takes a different bus, submitting the pre-trip inspection on that unit now updates the run's assigned unit to match. Dispatch sees the bus that is actually on the road. If the app is offline, the change is sent once it reconnects.
